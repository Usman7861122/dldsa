# DLDSA

Astro + React (when needed) + Tailwind CSS + Framer Motion.

## Start
```
npm install
npm run dev
```

## Folders
- `src/pages` - routes (each file = one page)
- `src/layouts` - page wrappers
- `src/components/sections` - big page parts (Astro)
- `src/components/ui` - small reusable parts
- `src/components/react` - React parts that need animation or state
- `src/styles/global.css` - Tailwind + design tokens
- `src/lib`, `src/hooks`, `src/data` - helpers, React hooks, content
- `public` - files served as they are
